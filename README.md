# arvane-perfume-store
Perfume E-Commerce Website – Academic Projec

 About the Project
Arvane is a perfume store website developed to provide users with an organized and enjoyable browsing experience. The project focuses on presenting perfumes through a user-friendly interface.
 Project Objectives
• Develop a website for a perfume store.
• Organize and display perfume products.
• Practice web development and server-side programming.
• Work with database management tools.
Technologies Used
• CSS: Styling and website layout.
• PHP: Server-side programming.
• XAMPP: Local development environment.
• Apache: Web server.
• phpMyAdmin: Database management.
 Features
• Perfume store website interface.
• Organized product presentation.
• Database management using phpMyAdmin.

Project Status
Completed.
 Project Purpose
This project was developed as a practical application of web development and database management skills.
